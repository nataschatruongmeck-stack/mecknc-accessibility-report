# MeckNC Accessibility Content Errors

WCAG 2.2 AA content errors for the Drupal sites on mecknc.gov, exported from the Acquia Web Governance API (snapshot: November 2, 2026).

Shared template issues (external-link and social media icons, empty component headings and lists, pagination) and errors from PDFs are set aside for the redesign and listed separately at the bottom of the page.

- `index.html`: the report page
- `data/`: the CSV files the page reads
